# Automação com Shell Script - IFTO

Repositório destinado às atividades da disciplina relacionadas à **Automação com Shell Script**, desenvolvidas no **Instituto Federal do Tocantins (IFTO)**.

## 📚 Sobre o projeto

Este repositório contém exercícios e atividades práticas utilizando **Shell Script no Linux**, com foco na automação de tarefas, manipulação de arquivos, uso de comandos do terminal e criação de scripts executáveis.

Para a realização das atividades, foi utilizado o **Microsoft Hyper-V** no Windows para criar e executar uma máquina virtual com Linux/Ubuntu.

## 🖥️ Ambiente utilizado

As atividades foram desenvolvidas em um ambiente Linux virtualizado utilizando o **Hyper-V**, recurso de virtualização da Microsoft.

Ambiente:

- Sistema operacional principal: Windows
- Plataforma de virtualização: Microsoft Hyper-V
- Sistema operacional da máquina virtual: Linux / Ubuntu
- Terminal utilizado: Bash
- Linguagem de script: Shell Script
- Controle de versão: Git
- Repositório remoto: GitHub

## 🛠️ Tecnologias e ferramentas utilizadas

- Windows
- Microsoft Hyper-V
- Linux / Ubuntu
- Bash
- Shell Script
- Terminal Linux
- Git
- GitHub

## ▶️ Como executar os scripts

Primeiro, abra o terminal da máquina virtual Linux.

Acesse a pasta do projeto:

```bash
cd Automa-o-com-Shell-Script---IFTO
```

Liste os arquivos:

```bash
ls -la
```

Dê permissão de execução ao script desejado:

```bash
chmod +x atividade.sh
```

Execute o script:

```bash
./atividade.sh
```

Também é possível executar utilizando o Bash:

```bash
bash atividade.sh
```

Para executar outra atividade:

```bash
chmod +x atividade12.sh
./atividade12.sh
```

Ou:

```bash
bash atividade12.sh
```

## 🐧 Utilização do Hyper-V

O **Microsoft Hyper-V** foi utilizado para criar uma máquina virtual Linux onde os scripts foram desenvolvidos e executados.

O ambiente utilizado segue aproximadamente esta estrutura:

```text
Windows
   │
   └── Microsoft Hyper-V
          │
          └── Máquina Virtual Linux / Ubuntu
                  │
                  ├── Terminal Bash
                  ├── Shell Script
                  ├── Git
                  └── GitHub
```

Essa configuração permite utilizar o ambiente Linux sem a necessidade de substituir o sistema operacional Windows instalado no computador.
